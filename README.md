# DS 623 Ethics Lab: scenario site

The interactive scenarios for DS 623, published with GitHub Pages. Each week is a folder with its own page:
- `week1/`: The Empty Chair (Ashgrove Health)

Link each week in Canvas as `https://<github user>.github.io/<this repository>/weekN/` (open in a new tab).
The top-level `index.html` lists every week.

To add or update a week, upload the new `weekN` folder from the course build package (same layout), replacing the old
one, together with the new `index.html` and this README. Packaged 2026-11-02.
People, organizations and data in the scenarios are fictional.
